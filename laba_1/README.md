# Лабораторная работа 1.

Реализованы: массив, односвязный список, двусвязный список, стек, очередь и дерево (Complete Binary Tree). Есть две версии, на C++ и на Go. Дерево сделано только на C++.

## Файлы

```
laba_1/
  include/     заголовки (.h)
  src/         реализация структур (.cpp)
  main.cpp     обработка команд
  Makefile
  go/          версия на Go
```

## Сборка и запуск (C++)

```
make
./dbms --file data.json --query "SPUSH 5"
```

Команду писать в кавычках.

## Сборка и запуск (Go)

```
cd go
go build -o dbms_go
./dbms_go --file data.json --query "SPUSH 5"
```

Обе версии используют один формат файла, поэтому можно запускать их на одном и том же data.json. Go-версия строку с деревом не трогает. Освобождать память в Go не нужно, это делает сборщик мусора.

## Команды

Первая буква показывает структуру: M - массив, F - односвязный список, L - двусвязный список, S - стек, Q - очередь, T - дерево.

Массив:
```
MPUSH x           добавить в конец
MINSERT 1 x       вставить по индексу
MGET 1            получить по индексу
MSET 1 x          заменить по индексу
MDEL 1            удалить по индексу
MLEN              длина
MPRINT            вывод
```

Односвязный список (для двусвязного то же самое, только с буквой L):
```
FPUSHH x          добавить в голову
FPUSHT x          добавить в хвост
FPUSHA a x        добавить x после элемента a
FPUSHB a x        добавить x перед элементом a
FDELH             удалить голову
FDELT             удалить хвост
FDELA a           удалить элемент после a
FDELB a           удалить элемент перед a
FDEL x            удалить по значению
FFIND x           поиск (TRUE / FALSE)
FPRINT            вывод с начала
FPRINTR           вывод с конца
```

Стек:
```
SPUSH x           положить
SPOP              снять и вывести
SPRINT            вывод
```

Очередь:
```
QPUSH x           добавить
QPOP              забрать и вывести
QPRINT            вывод
```

Дерево (только C++, ключи - числа):
```
TINSERT 5         добавить
TFIND 5           поиск (TRUE / FALSE)
TCOMPLETE         проверка, является ли дерево complete
TPRINT            обходы: прямой, симметричный, обратный, в ширину
```

Вывод любой структуры:
```
PRINT S           вместо S можно M, F, L, Q, T
```

## Пример

```
$ ./dbms --file data.json --query "SPUSH 5"
-> 5
$ ./dbms --file data.json --query "SPOP"
-> 5
$ ./dbms --file data.json --query "QPOP"
-> q
$ ./dbms --file data.json --query "TINSERT 1"
-> 1
$ ./dbms --file data.json --query "TCOMPLETE"
-> TRUE
```
